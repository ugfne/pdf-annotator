# Changelog

## 0.1.0

Initial baseline release of PDF Annotator.

- Direct PDF loading in a VS Code custom editor.
- Select, highlight, underline, pen, and eraser tools.
- Machine-readable `*.annotations.json` sidecar files with automatic saving.
- Resizable/collapsible annotation sidebar with comments and deletion.
- Fixed color palette plus custom color selection.
- Trackpad, button, fit-width, and slider zoom (25–200%).
- Page navigation and in-PDF text search.
- Undo/redo for annotation changes.
- Manual Save writes the current annotation state to JSON; annotation edits are also auto-saved.
- Show JSON and Create Markdown utilities.
- Symmetric left/right viewer spacing and responsive toolbar layout.
